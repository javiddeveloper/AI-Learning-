## Technology Selection Principle

Prefer stable, modern, production-oriented technologies. Do not introduce alternative tools unless there is a clear reason.

## Architecture Principle

Avoid premature abstractions and over-engineering. Start with the simplest architecture that solves the real problem and introduce abstractions when they provide measurable value.

## Learning Principle

A concept is considered learned only after explanation, practical implementation, and review.
